# Krathika Mendon — Personal Portfolio Website

🌐 **Live Site:** https://krathi-07.github.io/KrathikaMendon_Portfolio/

## About
Personal portfolio website built as part of the **EWB HTML & CSS Internship**.

## Features
- Responsive design (mobile + desktop)
- Dark / Light theme toggle
- CSS animations (gradient hero, fade-up, floating elements)
- Skills section with animated progress bars
- Projects showcase
- Contact section

## Tech Stack
- HTML5
- CSS3 (custom properties, keyframe animations, flexbox, grid)
- Vanilla JavaScript (theme toggle only)

## Sections
- **Hero** — Intro with animated gradient background
- **About** — Profile, stats, education
- **Skills** — Animated skill bars
- **Projects** — 4 project cards
- **Contact** — Contact form + links
